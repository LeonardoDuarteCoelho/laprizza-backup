LaPrizza Backups

A private integration for storing and recovering encrypted project backups in the team's Google Drive account.

Purpose and Google Drive access

The integration uses rclone to transfer backup archives to Google Drive. It requests the drive.file permission to manage files created by this integration, including uploading, listing, downloading and deleting its backup files.

Backup content and file names are encrypted using rclone crypt before being stored in Drive. Authorized operators keep the recovery secrets separately from the remote backup files.

Configuration status

This integration is being configured for SYS08. Database backup generation, scheduling, retention and recovery validation must be completed before routine operation.

This public website provides information about the integration. Backup files, account credentials and recovery secrets are kept in restricted storage.
